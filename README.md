# ROS2 Robotics Learning

ROS2 Jazzy robotics learning project on macOS Apple Silicon.

## Development Environment
- MacBook Pro M3 (18GB RAM)
- macOS ARM64
- ROS2 Jazzy
- RoboStack + Pixi
- Python
- Visual Studio Code

## Learning Roadmap
1. ROS2 Fundamentals
2. Python Nodes and Communication
3. Robot Control
4. Robot Simulation
5. Computer Vision-Based Robot Control
